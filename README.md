## Run it

```sh

```

## Why this line

A petty one-star-review voice aimed at the moon: it never shows up
during business hours, never answers, and still takes the credit for
the tides — the ocean does all the work while the moon takes the bow.
The "somehow" is the tell: the reviewer knows the moon did nothing
and is annoyed precisely because everyone else keeps praising it.
